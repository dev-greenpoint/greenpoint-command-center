# Recommended "Full Campaign" Master Workflow

For any campaign using multiple services, structure the board like this:

## Phase 1 — Campaign Setup
- Confirm client brief
- Confirm scope of services
- Confirm budget and hours
- Confirm campaign dates
- Confirm account team roles
- Set campaign objectives and KPIs
- Create campaign timeline
- Create approvals tracker
- Create asset folder
- Confirm reporting format

## Phase 2 — Strategy
- Develop campaign strategy
- Confirm audiences
- Confirm key messages
- Confirm channel approach
- Confirm risks and approvals
- Confirm measurement framework

## Phase 3 — Asset & Content Development
- PR materials
- Social calendar
- eDM copy/design
- Blog/web copy
- Influencer brief
- Event/activation plan
- Paid media assets
- Design assets
- Video/shortform shot lists

## Phase 4 — Approvals
- Internal review
- Client review
- Final amendments
- Final approval
- Pre-launch checklist

## Phase 5 — Execution
- PR pitching
- Social scheduling
- eDM send
- Influencer outreach/live content
- Event delivery
- Paid media launch
- Website/blog publish
- Design asset deployment

## Phase 6 — Monitoring
- Media coverage
- Social performance
- Paid performance
- Website/eDM performance
- Influencer content
- Event RSVPs/attendance
- Issues or risks

## Phase 7 — Reporting & Optimisation
- Coverage report
- Social report
- Paid report
- Influencer report
- Event report
- Campaign wrap-up
- Learnings and next recommendations
