# Campaign Structure Notes

## Recommended Campaign Board Sections

Reusable template with these sections:

- Campaign Admin
- Strategy
- PR
- PR Light
- Social Content
- eDM
- Web / Blog / Copy
- Influencer
- Shortform Capture
- Video Production
- Events & Partnerships
- Awards
- Paid Media
- Design
- Approvals
- Reporting
- Completed / Archive

## Standard Subtasks Per Service

Each service section should have these standard stages:

1. Brief
2. Strategy
3. Draft / production
4. Internal review
5. Client approval
6. Finalise
7. Publish / send / pitch / launch
8. Monitor
9. Report

## Service Separation Logic

Keep services distinct — don't let one become a catch-all bucket:

- **Content - Social** = ongoing calendar/content management
- **Content - Shortform Capture** = shoot/edit workflow
- **Content - Video Production** = larger production workflow
- **Design** = supports all content, PR, paid and events
- **Paid Media** = amplification layer, not just content
- **Brand Activation** = physical/community/partnership layer
